# C1.2 — node-agent sidecar + signature-request bridge @rule8

## Grounded node-agent facts (citrate-node-agent @ 09c8627)
- Binary `node-agent`, daemon via `--daemon` / env `CITRATE_NODE_AGENT_DAEMON=1`, positional
  `<compute.json>` (main.rs:87/:246).
- Supervision surface loopback-only `127.0.0.1:19600` (env `CITRATE_NODE_AGENT_ADDR`,
  server.rs:47); `GET /health` open; bearer-gated `GET /status`, `POST /pause|/resume`,
  `GET /signature-requests`, `POST /signature-requests/:id/observed`.
- Bearer = `Authorization: Bearer <hex64>`, `SupervisionAuth::generate` (32B→64 hex), persisted
  `0600` at env `CITRATE_NODE_AGENT_TOKEN_FILE` (auth.rs:40/:84). The file IS the IPC channel:
  `load_or_create` reuses an EXISTING non-empty token → citrate-core writes ITS minted token
  there first and the child adopts it.
- SignatureRequest wire = `PendingSignatureRequest` JSON (state.rs:87): `{id,intent,to,calldata,
  value_wei(decimal-str),chain_id,context,expires_block(decimal-str),status,tx_hash?}`.
  `claimRewards` is the earnings sweep (earnings/src/lib.rs).
