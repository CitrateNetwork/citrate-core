## Owner decisions (pending sign-off; defaults change nothing for members)

- A24: annotation trust stays "hints only" (MCP output is always untrusted); `allow_write_tools`
  stays false for `mem`, `scan` and member servers, and is true only for the built-in `node`
  entry, whose writes are approval requests in the app.
- The `node` entry defaults to off and needs the node MCP server on.
- MCP approval cards time out after 300 s (declined) and are shown only to an HIC-aware client.
- Reconnect backoff 1 s to 60 s; maintenance every 2 s; task deadline 600 s; poll interval
  clamped to 100 ms..10 s.

## Not done (honest)

- The recorded session is against the real node MCP server code in a test harness and the real
  release binary as the shim, not against the packaged app's UI; its ceremony is a harness
  record, not the SignatureCeremony (that needs the packaged app; anvil was not needed because
  nothing is signed until the member approves in the app).
- No official MCP conformance suite was run; conformance is shown by the fixture servers.
- `notifications/tasks`, persisting task ids across a restart, response caching, form-mode
  elicitation, sampling and roots are not implemented.
