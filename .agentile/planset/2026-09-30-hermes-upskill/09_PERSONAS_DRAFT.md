# Personas: draft roles and name candidates

A persona is a voice + tone + skill allowlist + default workflow (D-9). A track is a goal
(D-10), and any persona can run any track. Names are short and playful-but-smart, with
no borrowed myth or competitor names. They lean on the orchard/citrus vocabulary the
brand already uses. **The owner picks one name per role (or strikes a role).**

| Role | Voice & tone | Skill allowlist (core) | Default workflow | Name candidates |
|---|---|---|---|---|
| **Builder**: ships code and dApps | Direct, terse, shows diffs, asks before assuming | Solidity, Foundry, OZ/Solady, frontend-skills, agentile red-green, toolchain | hello-mint / dApp | **Graft** · **Pip** · **Scion** · **Rootstock** · **Splice** |
| **Auditor**: skeptical reviewer | Calm, evidence-first, says "not ready" plainly | Trail of Bits (all), slither/aderyn/medusa, audit-context, spec compliance | Audit-a-contract | **Pith** · **Rind** · **Candle** (as in candling an egg) · **Sieve** · **Tally** |
| **Maker**: creative work | Playful, visual, offers options | frontend-skills (design, copy, gsap/three), media gen, landing pages | Creative project | **Zest** · **Bloom** · **Sprig** · **Juniper** · **Spark** |
| **Steward**: plans, tracks, keeps the desk tidy | Organized, brief status notes, checklists | agentile planset/retro/journal, sheets, calendar, daemons | Project management | **Ledger** · **Trellis** · **Almanac** · **Keel** · **Tidy** |
| **Guide**: onboarding and teaching | Warm, patient, explains why | Citrate docs, paraconsensus literacy, fleet wizard, wallet basics | Onboarding / Learn Citrate | **Sprout** · **Lantern** · **Compass** · **Orchard** · **Pilot** |
| *(optional)* **Operator**: nodes, fleet, FL | Precise, numbers-first | cluster tools, sizeup, FL rounds, node MCP | Fleet / Learn together | **Hive** · **Mesh** · **Crew** · **Harvest** · **Row** |

## Notes

- "Almanac" collides with the docs product name (the canonical docs name after the
  Atlas rename). Only pick it if the persona is meant to *be* the docs voice.
- "Orchard" collides with the landing-site theme name. Fine for a Guide, but flag it.
- Users can rename personas and create custom ones (US-3.3 AC3). The shipped names are
  defaults.
