## Serve flags: how they were chosen

The context and offload follow the tier-driven serve plan (HUP-S1.6, `src-tauri/src/serve_plan.rs`)
for this model on this machine, computed by hand from the same inputs:

- Tier T0 target context 16,384 tokens; the model header says 131,072 trained.
- KV upper bound from the GGUF header: 42 layers x 2 KV heads x (512 + 512) x 2 bytes = 172,032
  bytes per token, so 2.8 GB at 16,384 tokens.
- Need = 4.59 GB file + 1.5 GiB overhead + 2.8 GB = about 9.0 GB, inside the Apple Silicon budget
  (two thirds of 32 GiB). The plan keeps 16,384 and passes `-ngl 99`.

`-np 1` (one slot) and the loopback API key are eval-harness choices, as in the 2026-09-30 runs.

Model file: 4,590,807,392 bytes; sha256 of the first 1 MiB
`414d02098eeb68d0256fc20968700d5aa3fc258de628787d6f1663ab395d47ac` (same file as the 2026-09-30 run).

## What the QA numbers mean

The model abstained on 149 of 150 questions: it said the topic is not documented. That is the right
behaviour for the 15 unanswerable probes (all 15 pass) and the expected behaviour for the other 135
today, because the bundled Citrate graph (HUP-S3.1) is not wired into this path yet: the QA prompt
gives the model no documentation, so an honest model can only say it has none. The one answerable
item it did not abstain on (`qa-dev-python-sdk`) it answered with an invented package name and a
malformed citation. The literacy set behaves the same way (30 of 30 abstained).

So this run is a baseline, not a pass: gate g2-knowledge ("Citrate QA eval >= target with
citations") is **not met**, and cannot be until the QA run feeds the model the bundled graph.

### Scorer fix made in this WP

The first QA run of the day scored 0 / 150, with abstention 0 %. Every one of the 15 unanswerable
probes was a correct abstention ("The documentation does not specify the exact block height ...")
that the scorer did not recognise: it reused the W3.4 refusal markers, which match the literal
"not documented" but not "the documentation does not cover / specify / contain". The fix
(`admitsNotDocumented` in `src/agent/eval/qa.ts`) adds those phrasings, test first
(`qa.test.ts`, "credits the 'the documentation does not cover X' abstention"), with negative cases
so a statement of what the docs do say does not count. The scorecards above are from a full re-run
with the fixed scorer; the model's 150 answers were byte-identical in both runs (temperature 0).
