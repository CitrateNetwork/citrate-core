# Citrate Core 0.5.7

0.5.7 is a hotfix, published as a **critical** update. It fixes the node repair added in 0.5.6:
the bundled node moves to citrate-chain `884555be`, so a node that set aside an old branch
reconnects to the network straight away instead of waiting for a restart. Your wallet, keys,
settings and chats are kept.

It is published to the update feed on Spaces with `--policy-min 0.5.4`
(docs/release/054-FORCED-UPDATE.md). The minimum stays 0.5.4, so no 0.5.4, 0.5.5 or 0.5.6 install
is blocked; there is no GitHub release. Hermes (citrate-agent-runtime `aa12b10e`) is the same build
as in 0.5.4 to 0.5.6.

## Update feed notes (RELEASE_NOTES)

The `[critical]` marker makes 0.5.4 and later download the update in the background and show the
red "Critical update available" card; the member still clicks Restart now. The card strips the
marker before showing the text.

```text
[critical] Citrate Core 0.5.7 fixes the node repair added in 0.5.6: after a node moves an old branch aside, it now reconnects to the network straight away instead of waiting for a restart. Restart to install. Your wallet, keys, settings and chats are kept.
```

## Node

- **A repaired node reconnects at once.** The bundled node is citrate-chain main `884555be` (was
  `7fb483e2`). It adds chain #489 (a node that cold-resynced writes its genesis before it binds
  it, and an empty chain that has heard no peer is never treated as synced) and #490 (a pending
  cold resync is carried out before the node opens its chain database, so the node starts on the
  fresh database and dials its peers, rather than coming up isolated until the next restart).
- The chain's lock moves `url` 2.5.8 to 2.5.9 and `form_urlencoded` 1.2.2 to 1.2.3
  (RUSTSEC-2026-0592).

## App

- **`url` 2.5.9 in Core's own lock** (RUSTSEC-2026-0592): `cargo update -p url --precise 2.5.9`
  moves `url` 2.5.8 to 2.5.9 and `form_urlencoded` 1.2.2 to 1.2.3; nothing else changes. No app
  code changes.

## Platforms

macOS (Apple silicon) and Linux x86_64 (AppImage and .deb). Linux aarch64 is not built for this
release; an aarch64 install is offered no update.
