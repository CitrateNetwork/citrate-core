# Citrate Core 0.5.6

0.5.6 is a patch release, published as a **critical** update. It carries one change: the bundled
node moves to citrate-chain `7fb483e2`, which repairs member nodes left on the old branch after
this week's network split. Your wallet, keys, settings and chats are kept.

It is published to the update feed on Spaces with `--policy-min 0.5.4`
(docs/release/054-FORCED-UPDATE.md). The minimum stays 0.5.4, so no 0.5.4 or 0.5.5 install is
blocked; there is no GitHub release. Hermes (citrate-agent-runtime `aa12b10e`) is the same build as
in 0.5.4 and 0.5.5.

## Update feed notes (RELEASE_NOTES)

The `[critical]` marker makes 0.5.4 and 0.5.5 download the update in the background and show the
red "Critical update available" card; the member still clicks Restart now. The card strips the
marker before showing the text.

```text
[critical] Citrate Core 0.5.6 repairs your node after this week's network split: if your node is stuck on the old branch, it detects that and resyncs to the current network by itself, keeping your keys. This can take about an hour after you restart. Restart to install. Your wallet, keys, settings and chats are kept.
```

## Node

- **A node stuck on the old branch repairs itself.** The bundled node is citrate-chain main
  `7fb483e2` (was `f4a0e600`). It includes chain #483 (header-first ancestor sync, so a node
  re-converges on the heavier branch), #488 (the CI harness for the multi-node sync tests) and #486
  (a node stranded on a dead branch far below its reorg floor resyncs itself, on evidence it can
  verify). When the node sees that evidence, it sets aside its chain data and resyncs from the
  current network. Its keys and identity files are kept.
- **No Core change is needed for this.** Core already restarts the node whenever it exits, and it
  writes no `[recovery]` section into the node's config, so the node's guarded cold resync is on.

## Platforms

macOS (Apple silicon) and Linux x86_64 (AppImage and .deb). Linux aarch64 is not built for this
release; an aarch64 install is offered no update.
