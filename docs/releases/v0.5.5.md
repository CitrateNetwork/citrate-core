# Citrate Core 0.5.5

0.5.5 is a patch release, published as a **critical** update. It fixes the first-run model
download, gives Hermes its terminal tools when you choose a cloud model, shows your node's sync
status honestly, and tells you when a membership is delayed instead of waiting forever. Your
wallet, keys, settings and chats are kept.

It is published to the update feed on Spaces with `--policy-min 0.5.4`
(docs/release/054-FORCED-UPDATE.md). The minimum stays 0.5.4, so no 0.5.4 install is blocked; there
is no GitHub release. The bundled node (citrate-chain `f4a0e600`) and Hermes (citrate-agent-runtime
`aa12b10e`) are the same builds as in 0.5.4.

## Update feed notes (RELEASE_NOTES)

The `[critical]` marker makes 0.5.4 download the update in the background and show the red
"Critical update available" card; the member still clicks Restart now. The card strips the marker
before showing the text.

```text
[critical] Citrate Core 0.5.5 fixes the first-run model download, gives Hermes its terminal tools when you choose a cloud model, shows your node's sync status honestly, and tells you when a membership is delayed instead of waiting forever. Restart to install. Your wallet, keys, settings and chats are kept.
```

## Local model

- **The first-run model download works again.** The download address the app used started
  answering with a web page instead of the model file, so the model step failed. The app now falls
  through to the model's direct source and resumes any partial download. The file is still checked
  against its pinned size and SHA-256 whatever the source. (#757)
- **Real error text.** When the download or the check fails, the model step shows the actual
  error instead of "download failed" or "unknown". (#757)
- **Correct model facts.** The model step shows the bundled model's real size, format and
  checksum (4.59 GB, Q4_0). (#757)

## Hermes

- **Terminal tools with a cloud model.** With terminal commands turned on and a cloud model chosen
  for Hermes (and no local model running), a message you route to the cloud model now runs in
  Hermes's own session, so its terminal, folder, web and MCP tools are offered. Before, Hermes
  answered that it had no terminal access. (#756)

## Node status

- **Sync measured against the public network.** "Syncing · N blocks behind" is measured to the
  public head, so a node a few blocks behind no longer reads as hundreds behind. (#758)
- **Honest during a network split.** When peers report blocks well above the public head, the
  status reads "Sync unknown · the network views disagree", and the Activate step's Node check
  stays closed with a line that says the network may be split. A node with no peers is never shown
  as synced. (#758)

## Membership

- **No endless "Waiting for checkout…".** When a membership grant is delayed on our side, the
  onboarding step shows a card that says so, with Check again and support@citrate.ai, instead of a
  spinner that runs for the whole wait. If your payment went through, the membership is recorded
  and finished automatically; there is no need to pay again. (#754)
