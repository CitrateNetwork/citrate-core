# Citrate Core 0.5.9

0.5.9 is a hotfix, published as a **required** update. It fixes joining groups, keeps the chat
relay connected, and says plainly when the private mesh is not available yet. Your wallet, keys,
settings and chats are kept.

It is published to the update feed on Spaces with `[critical]` and **`--policy-min 0.5.9`**
(docs/release/054-FORCED-UPDATE.md, owner decision 2026-11-23). The signed policy raises the
minimum to 0.5.9, so every 0.5.4 to 0.5.8 install shows the blocking update screen until it
installs 0.5.9. Installs older than 0.5.4 do not read the policy; `[critical]` makes them download
the update in the background and show the red card. There is no GitHub release.

The node stays at citrate-chain `68434069` and Hermes at citrate-agent-runtime `aa12b10e`, the
same builds as in 0.5.8.

## Comms

- **The bundled comms-member-daemon is citrate-comms main `f6652a56`** (was `9cd12c41`), the
  merge of comms #58. Its relay liveness probe no longer spends a sign-in challenge per status
  poll (the relay caps them per connection, so a healthy link read as down after about two and a
  half minutes), it keeps the link alive, redials a dropped link in the background with jittered
  backoff, and bounds its relay operations with timeouts.

## App (#770)

- **Joining a group works.** A join request no longer fails with "this device's group address
  isn't ready yet". Addresses are compared in one canonical form everywhere, including the roster
  check, so an add that landed is never mistaken for one that did not. The request on the wire
  keeps the `0x` form, so a 0.5.8 inviter still accepts a 0.5.9 request.
- **Mesh off says so.** While the private mesh is off, "Add a machine" and the group link answer
  "Mesh is not available yet" instead of a red error.
- **Honest relay status.** The relay chip reads "Reconnecting…" while the daemon redials, and
  "Relay down" with what to do when it cannot.
- **The comms daemon log is kept** (redacted, as the node and cluster daemon logs are), so
  support can read relay and socket errors.
- cookie 0.18.3.
