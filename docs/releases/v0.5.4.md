# Citrate Core 0.5.4

> Draft. This file is the source for the 0.5.4 release notes and for the `notes` field of
> `latest.json`. It is final when the release is cut. 0.5.4 is published to the update feed on
> Spaces with `--policy-min 0.5.4` (docs/release/054-FORCED-UPDATE.md); there is no GitHub release.

0.5.4 is a **required update**. It fixes node sync on the current test network, makes Hermes more
reliable, and from this version on lets the app require an update before it is used. Your wallet,
keys, settings and chats are kept.

## Update feed notes (RELEASE_NOTES)

The update card shows about the first three lines, so the first sentence carries the message. The
`[critical]` marker makes 0.5.3 download the update in the background and show the red "Critical
update available" card; the card strips the marker before showing the text.

```text
[critical] Citrate Core 0.5.4 is a required update: it fixes node sync and makes Hermes more reliable. Restart to install. Your wallet, keys, settings and chats are kept. From this version on, the app can require an update before it is used.
```

## Node sync

- **A new node no longer stalls while catching up.** Every fresh node stopped at block 1552 of the
  current test network; the bundled node now has the fix (citrate-chain #476).
- **Faster catch-up.** The node downloads blocks from several peers at once, in larger replies
  (citrate-chain #478).
- **Safer recovery.** A node that crashes during a fresh sync resumes cleanly (citrate-chain #480).
- **Settings › Node:** the CPU cap you set reaches the node, and the network row says which
  network this build joins. (#705)
- **Logs:** open the logs of all nine background services from the Node page. (#723)

## Required updates

- **The app can require an update.** A release can now set a minimum version, signed with the same
  key that signs the update files. Below it, the app shows only the update screen, downloads the
  update by itself and asks you to restart; it also offers a manual download link and support
  contact. An unsigned or unverifiable minimum is ignored. (#678, #698)
- **0.5.3 and older** cannot be blocked this way. They download 0.5.4 in the background and show a
  red update card; click Restart now to install.
- **Settings › Updates › Check now** runs a real update check. (#709)

## Hermes

- **Every connected model.** The model picker lists every local model and every model from a
  provider key you have connected, and the turn runs on the one you pick. (#670)
- **The API key field keeps what you type.** (#672)
- **No invented contract addresses.** Hermes reports a deployment only when a confirmed receipt
  shows it, including for turns started from the command line or MCP. (#680, #714)
- **An honest status.** The "Hermes is not running" warning reflects the real state. (#674)
- **Complete on install.** Skills, tools, prompts and resources are set up on install, with a setup
  self-check. (#677)
- **Your chats and projects are kept.** Chat history and Projects are stored sealed on this device
  and are easy to reach again. (#679)
- **More control over a running answer.** Stop or steer it, queue a message, edit and branch a
  chat, or retry with another model; each run shows a timeline and its receipts. (#686, #693)
- **Durable memory.** "Remember this fact" is written to memory and kept. (#704)
- **Scheduled tasks** run as Hermes turns when they are due. (#703)
- **Safer defaults.** Running node, npm scripts and git commits is no longer approved
  automatically; each build, test and git rule is opt-in per project. (#716)
- **Settings › Models:** connect a Devin key for the Cognition delegate. (#699)

## Layout

- The sidebar and the widgets and tutorials column collapse together.
- The message box grows as you type, and the mic and plan-it-first buttons no longer squeeze it.
  (#673)

## Groups and federated learning rounds

- **Groups:** new Chat, Members and Cluster boards. When @Hermes answers in a group, the message
  waits for your approval, after an on-device check for private information. (#684, #688, #730)
- **Rounds:** browse and join matches, follow a live round, draft a round, keep datasets on this
  device with a privacy scan and licence check before anything is shared, and review adapters
  against the evaluation gate. Opening a round is a draft only on this network. (#687, #692, #694,
  #696, #697, #715, #724, #732, #734, #738)
- **Settings › Work:** worker terms and consent. (#700)
- **Address book:** the round ledger and adapter factory contracts are read from the chain's
  address book. (#675)

## Not yet live

- **Payouts** and **the mesh** are visible in the app but not yet live. Nothing is
  paid out, and the mesh stays switched off in this release. (#695, #736)

## Fixes

- "Add server" opens the real MCP server editor; services that are not available say so. (#710)
- A saved auto-lock change applies to the open vault at once. (#718)
- Hermes › Controls › Records shows the approval records. (#719)
- A saved deploy record opens in full. (#726)
- Unused commands and placeholder code were removed; a local model that cannot be read says
  "read failed". (#729)

## Platforms

macOS (Apple silicon) and Linux x86_64 (AppImage and .deb). Linux aarch64 is not built for this
release; an aarch64 install is offered no update.
