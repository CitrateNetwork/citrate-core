# Citrate Core 0.5.8

0.5.8 is a hotfix, published as a **critical** update. It fixes the node stopping on Mac with
"too many open files" once its data grows, and makes the local model download reliable. Your
wallet, keys, settings and chats are kept.

It is published to the update feed on Spaces with `--policy-min 0.5.4`
(docs/release/054-FORCED-UPDATE.md). The minimum stays 0.5.4, so no 0.5.4 to 0.5.7 install is
blocked; there is no GitHub release. Hermes (citrate-agent-runtime `aa12b10e`) is the same build
as in 0.5.4 to 0.5.7.

## Update feed notes (RELEASE_NOTES)

The `[critical]` marker makes 0.5.4 and later download the update in the background and show the
red "Critical update available" card; the member still clicks Restart now. The card strips the
marker before showing the text.

```text
[critical] Citrate Core 0.5.8 fixes the node stopping on Mac with "too many open files" once its data grows, and makes the local model download reliable: it resumes after restarts and outages, checks your disk space first, and can be started any time from Settings. Restart to install. Your wallet, keys, settings and chats are kept.
```

## Node

- **No more "too many open files".** The bundled node is citrate-chain main `68434069` (was
  `884555be`). It adds chain #492: the node raises its open-file limit (RLIMIT_NOFILE) at start,
  and RocksDB's table cache is bounded (`max_open_files`), so a node whose database has grown no
  longer runs out of file descriptors and stops. The chain's lock is unchanged.

## App

- **The app raises its own open-file limit, and a crash-looping node says so** (#766): before any
  sidecar starts, the app lifts its soft RLIMIT_NOFILE (macOS gives a Finder or Dock launch 256)
  to at most 65536, capped at `kern.maxfilesperproc` on macOS, and every sidecar inherits it. When
  the node keeps stopping on start with the same error, Node > Status reads "Error · the node
  keeps stopping on start" with the node's own error line and the count, instead of "Starting".
  Citrate Core keeps retrying with backoff.
- **A local model download that holds up** (#767): onboarding's model download resumes after a
  restart, an expired link, a stall or an outage, checks free disk space before it starts, and can
  be started, paused or resumed any time from the new "Local model" card in Settings, with a
  smaller model option.

## Platforms

macOS (Apple silicon) and Linux x86_64 (AppImage and .deb). Linux aarch64 is not built for this
release; an aarch64 install is offered no update.
