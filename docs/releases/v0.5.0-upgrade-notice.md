# Citrate Core 0.4.x upgrade notice

Copy the text below as written. Short form first, for a banner or a chat message; the longer form
is for the release page and email.

## Short form

> Citrate Network has moved to a new chain. Update Citrate Core to 0.5.0 to rejoin. Your keys and
> wallet stay; your node resyncs the new chain from the start.

## Release page and member comms

> **Citrate Core 0.4.x: please update to 0.5.0**
>
> Citrate Network has moved to a new chain (chain id 40204, new genesis `[genesis hash]`).
> Citrate Core 0.4.x follows the old chain and can no longer join the network. Update to 0.5.0 to
> rejoin.
>
> - **Your keys and wallet stay.** Updating keeps your wallet, your node's keys and your settings.
>   You do not need to restore anything.
> - **Your node resyncs from the start.** On first launch, 0.5.0 clears the old chain's block data
>   (nothing else) and syncs the new chain from block 0. The app tells you when this happens. Leave
>   the app open until the node has caught up.
> - **How to update.** macOS and Linux: open Citrate Core and choose Update available, then Restart
>   now. Windows: download the 0.5.0 installer from citrate.ai and run it; there is no in-app
>   updater on Windows yet.
>
> If the app says an older Citrate node is still running, quit Citrate Core, wait a few seconds and
> open it again. If that does not clear it, restart your computer.
